# Context Switch

## Vision

A local-first browser game about shipping software with fallible fictional coding agents. The player starts with two shells and one execution slot, launches anthill or forge by command, then becomes an orchestrator of parallel work, quota switching, evidence-based reviews and causal repairs.

All providers, models, output, tickets, files, quotas and incidents are locally simulated. No AI APIs, account connections, real repository access, analytics or authentication.

## Product principles

1. Waiting is not the focus: keep work passes short and decisions available.
2. Agent conversation accepts natural language; terminal commands enforce shell syntax.
3. More sessions create output and a larger review queue.
4. Bugs arise from visible earlier decisions, and repairs change later callbacks.
5. The actual player supplies judgment; there is no human attention/bandwidth resource.
6. Tabs, monitors and panes unlock toward a multiplexer; dashboard is an upgrade.
7. Industry references use fictional authored events, not live news ingestion.

Fictional ecosystems remain recognisable through original names, model families, quota policies and CLI conventions; no real marks, logos or model identifiers in player-facing copy.
