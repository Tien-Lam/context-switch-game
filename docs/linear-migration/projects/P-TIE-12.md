# Delivered terminal workspace

Fresh runs open two shells. Type anthill or forge directly to launch distinct fictional full-window provider CLIs. Agent conversation accepts natural requests; Terminal tools enforce documented syntax. Separate drafts/history and selected tab persist. Exit/Ctrl+D returns to shell; same provider resumes; background work continues.

One shipment unlocks a second execution slot/additional tabs; two unlock naming/quota-plan guidance; three unlock a third slot, monitors and split/swap/close panes. Dashboard is purchased.

Shared virtual files, per-tab cwd/OLDPWD, navigation/text/file tools, quoting, read-only pipes/game-tool pipes, &&/semicolon chains, input/output redirection, HOME/PWD variables, tilde/globs, completion, Ctrl+C/Ctrl+L and simulated read-only Git are delivered. Mutating game tools and provider launch run directly rather than in compounds. This is a deterministic subset, not POSIX/process execution; file edits do not complete tickets. [TIE-331](https://github.com/Tien-Lam/context-switch-game/issues/29) and specialist/browser QA close the previously tracked gaps.
