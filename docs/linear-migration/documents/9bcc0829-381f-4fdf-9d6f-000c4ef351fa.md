# Scope

PERF-204 offers restoring invalidation (fresh and fast, full reward) or bypassing cache (fresh but slow, reduced reward). Bypass unlocks optional PERF-205 to recover performance; finale never requires that follow-up.

# Workflows

Ledger: 5 seconds, 3 upfront provider quota, +12 context, one slot. Isolated probes: 3 seconds, no upfront quota, +3 context, one primary plus one actual supporting slot; helper uses half the model quota rate. Anthill defaults ledger; Forge defaults probes when a helper is available, otherwise explains ledger fallback. Either provider supports either workflow. Bypass: 1.5 seconds, +2 context, reward 7 instead of 12; follow-up takes 6 seconds and pays remaining 5.

# UI

Natural-language requests inside agents; strict flag syntax only in terminal tools. Show scope kept/lost, review evidence, helper ownership and action-specific costs. No new APP-101 burden, best-fit badge or global dispatch optimization preview.

# Acceptance

Focused deterministic tests; atomic rejection when explicit probes has no free slot; helper lifecycle/quota correctness; save v9 migration and malformed-reference validation; optional route excluded from required campaign score; distinct later evidence for restored/bypassed/stale. Independent review and actual browser playthrough with corrective iteration. Automated gates and verified hosted build. Agent evidence is not claimed as human fun validation.
