# Playable alpha specification

Updated 2026-10-05 (Australia/Sydney) for release [740c4b5](https://github.com/Tien-Lam/context-switch-game/commit/740c4b59ba06b43a5cdf9fd9216959fe4488a588). Two review rounds plus all five specialist charters were exercised; agent-operated browser observations are distinct from human-player research.

## Player promise and current delivery

Run a fictional engineering shift in a CLI-focused browser terminal. [Hosted alpha](https://tien-lam.github.io/context-switch-game/) and [source](https://github.com/Tien-Lam/context-switch-game/) are available. The earlier local-only deployment choice was superseded by the user's GitHub Pages request.

The game is locally scripted, with no real coding agents, APIs, accounts or repository connections. Agent conversation is natural-language; shell commands are exact and execute only against simulated state.

## Progression

1. Start with two shells, both fictional provider CLIs installed and one execution slot. Type anthill or forge to launch one.
2. First shipment unlocks a second slot and additional terminal tabs.
3. Second shipment unlocks naming and triggers an authored Anthill quota-plan change; Forge retains its separate pool.
4. Third shipment unlocks a third slot, live monitors and split/swap/close panes.
5. The graphical dashboard is an optional purchased upgrade.
6. Reviews/defects create conditional repairs, change downstream audits and affect the ending.

## Two-chapter campaign

16 main tickets: 9 in the initial investor-demo arc, then 7 covering green-build test integrity, account API/panel contracts, retry behaviour, gateway rollout and SHIP-2.

7 conditional repair tickets address privacy, cache invalidation, runtime drift, parallel merge risk, test integrity, contract mismatch and retry loops. Clean runs do not get phantom repairs. Unresolved earlier shortcuts produce explicit callbacks. Live gateway response distinguishes scale, rate-limit and rollback; blocked repairs remain retryable once their prerequisites are met.

## Review and pacing

Reviews show summary, touched files, tests, warnings, risk-source breakdown and PASS/BLOCKED decision guide. High aggregate risk can block despite green test signals. Approve accepts risk, revise consumes another pass, escalate safely resolves but costs trust/reward.

Typical intended passes take roughly 3–16 seconds, while the player reads, switches, reviews or starts parallel work. There is no attention/bandwidth resource. Throughput counts total shift time, including idle waits. Overall session duration and human-player enjoyment are still unvalidated.

## Terminal, sandbox and alpha controls

Shared virtual filesystem, per-tab cwd, standard navigation/text/file commands, quoted arguments, simple builtin pipelines and output redirection. Agent/Terminal surfaces retain independent drafts/history. This is not a complete POSIX shell or real process runtime. Filesystem edits cannot bypass ticket rules.

trace displays local event/counter evidence; sound on|off controls an optional review chime; motion reduce|auto follows override or system preference. Save export/import and confirmed restart are local. Save envelope version 8 supports sequential migrations and validation. Sandbox files are separate from game JSON export and reset on restart/import.

Production static hosting uses the configured repository base path and a service worker with cached offline fallback after load. There is no cold-offline guarantee or runtime gameplay API.

## Shell and QA completion — 2026-10-05

Delivered shell semantics: &&/; chaining, < input redirection, > and >> output, HOME/PWD/OLDPWD expansion, tilde paths, segment \* / ? globs (including relative parents), cd -, and read-only game-tool pipelines. Quoted/escaped patterns stay literal; no word splitting, arbitrary variables, scripts, substitution, background processes or real shell. Game mutations run directly, not inside chains/pipes.

Tab completes shell commands/paths; Ctrl+C clears unselected input without cancelling scripted work; Ctrl+L clears the current transcript; Shift+Tab retains keyboard navigation. exit, /exit or Ctrl+D on empty input returns to shell; the same provider command resumes the conversation. Background work retains ownership. Use another tab for another provider while this tab owns unfinished work.

Provider banners/status reflect cwd, selected terminal restores after reload, histories work at capacity, optional UI storage failure does not crash play. /help is discoverable from shell help; unlock events follow the owning tab's current surface; revision responses identify their slot. Unsupported sandbox-file requests in Agent offer a plain-language Terminal recovery path.

Save snapshots retain simulated timestamps; optional validated snapshotSequence orders same-clock writes correctly whether DB or emergency storage lags. Legacy version-8 saves remain compatible. Duplicate ticket occupancy and active/completed conflicts reject. Storage reads/clear recover safely, review IDs are stable at fractional boundaries, ending upgrades reject, and risk forecasts account for expected work-context decay.

Mixed-branch contract callbacks no longer blame a repaired branch. Deterministic conservative/reckless/mixed/early-repair routes still reach SHIP-2 with causal endings. Sandbox edits still do not complete tickets; no AI/network runtime was added.

## Final storage fallback audit

Final audit fix [TIE-344](https://github.com/Tien-Lam/context-switch-game/issues/39) keeps valid imports, restart and gameplay operational if browser persistence is unavailable. Either save backend can succeed; when neither can write, an explicit not-saved warning advises exporting before close/reload. Background saves do not reject unhandled, UI/workspace resets finish, and stale snapshot failures cannot overwrite a newer save's status. Five additional unit regressions and a dual-denied-storage scenario on desktop/mobile pass; 107 unit/scenario tests and 50 browser runs (25 scenarios × two Chromium configurations). Earlier live-campaign and keyboard evidence retains its own build attribution in the [QA report](https://github.com/Tien-Lam/context-switch-game/blob/main/docs/linear-migration/documents/fb98360a-fb99-4de8-82bc-126a81544525.md).

[TIE-345](https://github.com/Tien-Lam/context-switch-game/issues/40) prevents restored event announcements from replaying when hydration finishes. The event cursor is seeded only after the saved run loads; new live events still route normally. Offline catch-up progress remains inspectable via reviews/events and the catch-up notice rather than replaying saved transcript alerts. A desktop/mobile reload regression retains exactly one fresh shipment announcement.
