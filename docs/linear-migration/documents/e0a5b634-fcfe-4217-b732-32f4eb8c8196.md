## Findings that justify work

An explicit disabled-default task request starts unchanged work. Conversational model/plan/upgrade inquiries can fall back to irrelevant next-ticket text. Prelaunch estimates print undefined reasoning. Cross-provider approvals execute correctly but conceal their consequence in the owning transcript. Generic revisions omit useful cost information, and SHIP-1 can change gate with identical completed evidence. SHIP-2 can say checkout checks pass while acknowledging a missing assertion. Medium reasoning dominates low; sampled scope paths converge on identical ending scores as trust saturates. Capability hints and recovery acknowledgment have bounded improvement hypotheses.
